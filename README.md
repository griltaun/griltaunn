# Домашняя кухня — сайт с корзиной и заказом через WhatsApp

## Заказы
Корзина и форма заказа работают в браузере. После оформления сайт открывает WhatsApp с заполненным сообщением для кафе. Покупателю нужно нажать «Отправить» в WhatsApp, чтобы заказ пришёл вам.
Номер настроен на +7 (995) 290-62-62.

Важно: WhatsApp не отправляет сообщение автоматически — пользователь подтверждает отправку. Для настоящей автоматической отправки без участия клиента нужен WhatsApp Business Platform/API и сервер.

## Каталог и фотографии
Каталог редактируется в начале `script.js`: `name`, `cat`, `price`, `desc`, `img`.
Положите фотографии в `assets/` с теми именами, что указаны в каталоге. Для верхнего фото используйте `assets/hero.jpg`.
Фотография меню из переписки в архив не добавлена.

## GitHub Pages
Создайте репозиторий, загрузите содержимое архива, затем Settings → Pages → Deploy from a branch → main → /(root) → Save.
